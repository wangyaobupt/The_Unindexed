title: "AI to C 的成本是可解的"
---

这篇文章来自 James 在腾讯 2026 年 Q1 业绩后与投资机构小范围深度交流里的一段话。他的原话是：

> 但我认为有理由乐观。我们知道，在 Token 业务中，如果 Prompt 是独特的、差异化的 Prompt，并且确实需要运行完整推理模型，那么成本就很高。另一方面，如果 Prompt 是模型以前见过的 Prompt 的重复，那么你可以把它送到 KV Cache，那就非常便宜。所以随着时间推移，我们围绕 Hunyuan 3 和 Hunyuan 4 所做的一些协同设计和系统封装，专门就是为了优化 Prompt 分配到 KV Cache 与分配到完整推理之间的比例，从而降低成本。

这段话把 AI to C 的成本问题切开了。过去我对 C 端 Chatbot 的商业模型比较悲观，因为它看起来像一门天然难看的生意：用户什么都问，每一次回答都烧推理算力，但普通用户的大量问题又没有足够高的商业价值。一个人问职业选择，另一个人问楼下餐厅几点开门，如果都要走一次完整推理链路，那么其账单是谁也支付不起的。这个判断本身没错，但它的前提错了：绝大多数C端问题不应该被当成一次新的、完整的、前沿认知来处理。

大多数 C 端请求没有想象中那么独特。社交网络已经反复说明，人群的注意力是高度同步的。每天真正流动的，不过是同一批热点、同一批新闻、同一批消费疑问、同一批情绪困境、同一批学习和工作模板。用户觉得自己在问一个私人问题，系统看到的却可能是一个巨大的相似问题簇。今天很多人问“这个新闻怎么看”，明天很多人问“这个产品值不值得买”，后天很多人问“这段关系是不是有问题”。表达不同，底层结构很接近。每一次都走最贵的完整推理链路，这说明产品系统还没有学会分流。

真正可行的 AI to C，应该把用户请求分成两类。一类是前沿认知：新的、高价值的、不确定的、需要真正推理的问题。写代码、做研究、复杂决策、专业分析、长链路规划，这些请求应该付高价，也值得用最强模型。另一类是重复认知：常见的、社会同步的、结构已经被大量验证过的问题。这部分不该反复消耗最贵算力，它应该被 cache 化、模板化、分层路由，用更便宜的系统完成。工程上可以有很多形态：KV Cache、语义缓存、小模型分流、端侧补全、预计算答案。核心不是某个名词，而是把一部分“智能”从实时完整推理里拆出来，变成可复用资产。

这里最容易被低估的是第三层：个性化。很多人会以为，一旦答案来自 cache，用户就会觉得它不够聪明、不够懂自己。但个性化未必需要从头跑一遍最贵模型。用户记忆、长期上下文、语气偏好、常见约束，可以作为一层轻量 overlay 叠在重复认知之上。底层答案来自被摊薄的通用认知，上层再按用户的处境、口味和表达方式做调整。对用户来说，他感受到的是“它懂我”；对系统来说，最重的计算并没有每次重新发生。

沿着这个方向看，公司越来越重地投入 prompt classification、routing、cache systems、speculative decoding、small-model delegation、retrieval systems、memory systems 和 workflow orchestration，就不只是工程细节的堆叠。这些东西表面上分散，底层都服务同一个目标：判断一次请求到底该被送到哪里，应该调动多少计算，哪些上下文可以复用，哪些记忆需要进入最后一层回答。模型当然仍然重要，但它可能最终只会成为 stack 里的一层。这已经不是纯粹的推测。OpenAI 在 [GPT-5 发布说明](https://openai.com/index/introducing-gpt-5/)里把 GPT-5 描述成一个 unified system：高效模型处理多数问题，deeper reasoning model 处理更难的问题，中间由 real-time router 根据 conversation type、complexity、tool needs 和用户显式意图决定走哪条路径。它还说，这个 router 会继续用用户切换模型、偏好率和正确性等真实信号训练。另一个关于 ["Used GPT-5" 标记的说明](https://help.openai.com/en/articles/12454167)则写得更细，某些敏感对话会按单条 message 临时 route 到更合适的模型。也就是说，至少在 ChatGPT 身上，classification 和 routing 已经是产品系统的一部分。

这会把 AI to C 的经济结构改写成一个更正常的分层生意。少数真正需要前沿认知的人，为前沿模型付费；多数普通用户的大量重复请求，通过缓存和分流被低成本服务；个性化层负责让低成本答案不显得廉价。这样一来，C 端 Chatbot 不必永远陷在“免费获客”和“推理亏损”之间。它可以把最贵的 intelligence 卖给最愿意付费的人，把可复用的 intelligence 摊薄给大众，再用轻量个性化维持体验。
